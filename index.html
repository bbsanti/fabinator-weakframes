Fabinator WeakFrames

Review weak frames → build a Fabinator-ready video · everything runs locally in your browser

What this app is for

This app is used to review weak frames — frames where the segmentation model struggled — and put the keepers into a video to be used in the Fabinator.

Frames are reviewed as pairs: the original frame (0.bmp) and its annotated counterpart (segmneted_0.bmp). You judge each pair, throw out the weak ones that won't help, and export the survivors as a frame-exact video.

Your images never leave this machine. Files are read and written directly on your disk, and the video is encoded in-browser with FFmpeg (WebAssembly).

✅ A good weak frame…

  • has all elements clearly visible
  • has errors in the annotation that show where the model fails
  • is varied from the other weak frames before and after it

🚫 A bad weak frame…

  • is blurry to the point limbs, balls, and other objects aren't clearly delineated
  • has many elements that aren't relevant to the model (like camera angles we don't augment on)
  • is very similar to the frames around it and won't help the model generalize

How to use it

  1. Frame Review — open your frames folder (subfolders are scanned automatically). The app finds every #.<ext> + segmneted_#.<ext> pair.
  2. Step through with the keyboard, toggling original ⇄ segmented to spot where the model fails. Mark rejects — they move to a to_delete folder first, so nothing is gone until you explicitly hit Delete selected permanently. Undo works the whole time.
  3. Video for Fabinator — export the surviving frames as ProRes 422 LT at 59.94 fps (or ProRes Proxy / H.264). Every frame goes in exactly once: no interpolation, no scaling, no duplicates.

Requirements

  • Chrome or Edge on desktop — the folder access API is not in Firefox/Safari.
  • First export downloads the FFmpeg engine once (~31 MB), then it's cached.
  • Works from a web URL (e.g. GitHub Pages) or a local server — processing is always local.
